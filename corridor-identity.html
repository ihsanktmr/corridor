The primary line names the actual value prop — value survives the crossing — instead of generic speed or borderless language every remittance app already uses. It reads as one plain sentence, no crypto jargon, which is the point: it should make sense to someone who has never touched a wallet.

logo mark — direction

The mark is a one-point-perspective passage: a near wall and a far wall, joined by a single sightline. It reads as an abstract corridor and, at a glance, as a route on a map — a line from one point to another. This is a direction to react to, not a final lockup; production refinement (stroke weights, optical balance, a locked grid) comes once the direction is approved.
